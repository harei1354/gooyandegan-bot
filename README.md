# ربات مدیر سوپرگروه گویندگان

## راه‌اندازی
1. Python 3.10+ نصب کنید و `pip install -r requirements.txt` اجرا کنید.
2. فایل `schema.sql` را در Supabase → SQL Editor اجرا کنید.
3. در Telegram BotFather یک bot بسازید و آن را به گروه با دسترسی حذف پیام، محدود/اخراج کاربر و ارسال پیام اضافه کنید. برای استقبال خودکار، privacy mode را در BotFather خاموش کنید و ربات را مدیر گروه کنید.
4. متغیرهای محیطی را تنظیم کنید (هیچ کلید محرمانه‌ای داخل فایل کد نیست):
   - `BOT_TOKEN`: توکن صادرشده از BotFather (به‌صورت متغیر محیطی امن)
   - `SUPABASE_URL`: آدرس پروژه
   - `SUPABASE_SERVICE_ROLE_KEY`: کلید service_role؛ هرگز عمومی یا در مخزن کد نگذارید
   - `GROUP_ID`: شناسه عددی سوپرگروه
   - `ADMIN_IDS`: شناسه عددی مدیران ربات، جداشده با کاما
   - `TOPIC_MAP`: اختیاری؛ JSON از `thread_id` به دسته
   - `FORBIDDEN_WORDS`: اختیاری؛ فهرست واژه‌ها با کاما. فهرست واژگان باید متناسب با سیاست گروه تنظیم شود.
5. اجرا: `python bot.py`

## تنظیم موضوع‌ها
شناسه‌های ارسالی مالک گروه در تنظیم پیش‌فرض آمده‌اند: 1, 213, 14, 71, 3, 66, 72, 4. نگاشت پیش‌فرض دسته‌ها صرفاً جایگزین آغازین است؛ قبل از اجرا آن را با عنوان واقعی موضوع‌های گروه تطبیق دهید. دسته‌های معتبر: `general`, `samples`, `projects`, `intro`, `rules`, `tariffs`, `podcast`, `other`. نمونه:
`TOPIC_MAP={"1":"rules","213":"samples","14":"projects","71":"intro","3":"general","66":"tariffs","72":"podcast","4":"other"}`

درخواست پروژه در پیام خصوصی ربات می‌آید و با دکمه برای مدیران ارسال می‌شود؛ ربات فقط پس از تأیید در موضوع `projects` منتشر می‌کند. ربات را به‌عنوان مدیر با دسترسی‌های لازم منصوب کنید. محدودیت‌های ساعتانه و سقف نمونه‌کار/معرفی از قواعد ارائه‌شده پیاده شده‌اند.

## نکات
- کلید Supabase service role صلاحیت کامل دیتابیس دارد؛ فقط در محیط امن میزبانی قرار دهید.
- اجرای چند نمونه همزمان توصیه نمی‌شود: شمارش عمومی هر ساعت در حافظه همان پردازه نگهداری می‌شود.
- بررسی محتوای تکراری بر مبنای متن/شناسه رسانه است؛ برای رسانه‌های بدون متن، تقویت‌پذیر است.
- واژگان رکیک از پیش حدس زده نشده‌اند تا از حذف اشتباهی پیام جلوگیری شود؛ فهرست `FORBIDDEN_WORDS` را مدیر گروه تعیین کند.
